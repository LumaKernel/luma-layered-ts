# luma-layered-ts

TypeScriptレイヤードアーキテクチャ。Effect.tsベース。

## 導入

以下を対象プロジェクトのClaudeに貼る。

```
https://github.com/LumaKernel/luma-layered-ts の prompts/init.md を読み、その手順に従ってこのプロジェクトにluma-layered-tsを導入せよ。
```

## 構成

- `prompts/` - 仕様(Claude向け)
- `packages/types/` - `@luma-layered-ts/types`
- `packages/eslint-plugin/` - `@luma-layered-ts/eslint-plugin`
